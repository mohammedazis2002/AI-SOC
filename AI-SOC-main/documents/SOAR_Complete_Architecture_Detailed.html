📋 Complete Processing Flow Summary

Main Alert Processing Path (Synchronous):

Wazuh → Load Balancer → Ingestion Service → Redis Queue → Enrichment Services (Parallel) → ML Models (Sequential: Anomaly → FP → Root Cause) → RAG Retrieval → Agent 1 (LLM Analysis) → Agent 3 (Verification) → Agent 4 (RL Recommendation) → Decision Engine → Response Executor → Storage → Dashboard Update → Feedback Loop
Background Processes (Async):

• Model 4 (Attack Chain Detection): Runs every 5 minutes
• Agent 2 (Threat Hunting): Runs every hour
• Agent 5 (Forecasting): Runs every 6 hours
• Feedback Collection: Continuous (waits for outcomes)
• Model Retraining: Weekly (or on-demand)
